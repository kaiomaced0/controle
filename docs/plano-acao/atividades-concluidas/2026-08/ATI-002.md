# ATI-002 — Scaffold do servidor do PC (Node 22 + TypeScript)

## Objetivo
Criar o esqueleto do servidor em `server/`, com build, execução em modo desenvolvimento,
configuração e log — a base onde tudo do lado do PC vai morar.

## Escopo
- `server/package.json` (ESM, Node >= 22), `tsconfig.json` estrito.
- Estrutura de pastas conforme a arquitetura: `src/transporte/`, `src/protocolo/`,
  `src/movimento/`, `src/perfis/`, `src/saida/`, `src/cli/`.
- Scripts: `dev` (execução com recarga), `build`, `start`, `typecheck`, `lint`, `test`.
- Carga de configuração (porta, taxa, nível de log) por arquivo + variáveis de ambiente,
  com valores padrão declarados em um único módulo `config.ts`.
- Log estruturado com níveis; **nada de log por pacote no caminho quente**.
- Runner de testes nativo do Node (`node:test`) configurado com um teste de fumaça.

## Fora do escopo
WebSocket, protocolo, injeção de entrada — cada um tem sua própria atividade.

## Critérios de aceite
- [ ] `npm run dev` sobe o processo e encerra limpo com Ctrl+C (sem handle pendente).
- [ ] `npm run typecheck` passa com `strict: true` e sem `any` implícito.
- [ ] `npm test` executa e passa.
- [ ] Configuração documentada no README do `server/` com os padrões e como sobrescrever.
- [ ] Dependências de produção limitadas ao necessário; nada de framework web.

## Notas
Node 22 tem `--experimental-strip-types`; ainda assim usamos build explícito para o
empacotamento da fase 7. A decisão de bundler (se houver) fica para essa fase.
