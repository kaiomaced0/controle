# ATI-001 — Fundação do repositório, documentação base e fluxo de agentes

## Objetivo
Ter o repositório navegável, o produto descrito por escrito e o processo de trabalho
(desenvolvedor ⇄ revisor) pronto, para que qualquer atividade seguinte comece com contexto.

## Escopo
- README com o que é o projeto, stack, estrutura, requisitos e como rodar.
- `docs/VISAO.md` — problema, princípios, escopo, roadmap por fases, requisitos, riscos.
- `docs/ARQUITETURA.md` — componentes, pipeline de movimento, perfis, transporte, ADRs.
- `docs/PROTOCOLO.md` — contrato de mensagens JSON e pacotes binários (v0.1).
- Projeto React Native *bare* em `app/` (Android configurado, iOS presente para a fase 6).
- Plano de ação em `docs/plano-acao/` no modelo meta → sprint → atividade.
- Skills e subagentes em `.claude/`: `desenvolvedor` e `revisor`.
- `CLAUDE.md` do repositório com as regras para agentes.

## Fora do escopo
Qualquer código funcional de servidor, transporte ou sensor.

## Critérios de aceite
- [x] `npm start` e `npm run android` disponíveis em `app/` com RN 0.87 instalado.
- [x] `applicationId` = `com.nortedata.controle`; nome exibido = Controle.
- [x] Quatro documentos base escritos e ligados entre si por links.
- [x] Skills `desenvolvedor` e `revisor` com fluxo de aprovação/devolução definido.
- [x] Plano de ação com as atividades das fases 0 a 5 registradas.

## Notas
Ambiente verificado nesta máquina: Node 22.13.1, npm 11.6.1, JDK 21.0.3, Android SDK em
`D:\Android\Sdk` (platform-tools 36.0.0, NDK e emulador presentes).
