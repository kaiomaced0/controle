# ATI-010 — Perfil Mouse básico: tela com botões, cliques e scroll

## Objetivo
A primeira tela de controle de verdade: botões do mouse na tela do celular, com o cursor
sendo movido pelo giroscópio.

## Escopo
- Perfil `mouse-basico` em `server/perfis/mouse-basico.json`, conforme o esboço da
  ARQUITETURA.md, seção 4.
- Tela no app renderizando esse perfil (nesta ATI pode ser renderização direta; a engine
  genérica de perfis é o sprint 4).
- Controles: clique esquerdo, direito, do meio, faixa de scroll vertical, centralizar e
  sincronizar.
- Botões enviam `down` e `up` separados — arrastar precisa funcionar (selecionar texto,
  mover janela).
- Faixa de scroll: arrastar o dedo gera passos fracionários de roda, com vibração `tick` a
  cada passo (a detente é o que dá sensação de roda física).
- Toque responde em menos de 50 ms com retorno visual **e** háptico.
- Segurança: soltar todos os botões ao perder a conexão ou ao sair do perfil.

## Fora do escopo
Engine declarativa genérica (ATI-017) e editor de perfis (ATI-019).

## Critérios de aceite
- [ ] Dá para abrir uma pasta com duplo clique, arrastar um arquivo e rolar uma página
      longa usando só o celular.
- [ ] Menu de contexto abre com o botão direito e fecha com o esquerdo.
- [ ] Nenhum botão fica preso após desconexão forçada (cabo removido com o dedo na tela).
- [ ] Scroll tem sensação de passo (vibração por detente) e não dispara em rajada.
- [ ] Layout continua utilizável com o aparelho em pé, segurado com uma mão só.

## Notas
Este é o perfil de referência da VISAO.md: se ele estiver bom, os outros perfis são
recombinação das mesmas peças.
