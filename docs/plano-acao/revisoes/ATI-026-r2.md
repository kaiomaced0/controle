### Apontamento #1 — a bancada rodada contra uma API falsa, com cada `SetCursorPos` registrado

Para provar a trava do `--borda` sem roubar o mouse de quem usa a máquina, rodei a própria
`ferramentas/provar-aceleracao.mjs`, sem alterar uma linha dela, com duas travas:

- **Gancho de resolução de módulo.** Ele troca `src/saida/windows/api.ts` por uma API falsa, que
  simula a área virtual, a curva (o modelo de regime do próprio projeto) e a régua absoluta.
- **`koffi.load` bloqueado**, nas portas CJS e ESM. Se algo chegasse à `user32.dll` de verdade,
  explodiria antes de qualquer injeção. Conferi a trava à parte: a API real lança
  `não consegui carregar user32.dll...`.

Antes de confiar no gancho, testei a troca com um roteiro que só lê. A primeira montagem **não**
pegava os módulos importados de dentro do `backend.ts`, e a sonda leu a posição real do cursor
(nenhuma injeção aconteceu). Por isso entrou a segunda trava. Só rodei a bancada depois de a sonda
ler o cursor falso pelos dois caminhos.

| Execução | `SetCursorPos` registrados | Maior afastamento real do centro (todo evento) | Linha `afastamento` da bancada | Eventos com botão |
|---|---|---|---|---|
| padrão, 1 monitor | `(960,540)` × 44, depois `(111,222)` (origem) | x 188 · y 34 | 188 / 34 | 0 |
| padrão, 2 monitores (área 3000×1920) | `(960,540)` × 44, depois `(111,222)` | x 188 · y 34 | 188 / 34 | 0 |
| `--borda`, 2 monitores | `(960,540)` × 44, **`(2990,540)`**, **`(1915,540)`**, `(111,222)` | x 188 · y 34 na parte padrão | 188 / 34 | 0 |

- **Sem `--borda`, nenhum salto para longe do centro.** O `if (!COM_BORDA)` de

- **Com `--borda`, os saltos são exatamente os documentados.** O primeiro vai a x = 2990, a borda do
  segundo monitor, e dá `não grudou` (2990 → 2999 → 2989). O segundo vai a x = 1915 e dá
  `ATRAVESSOU` (→ 1925).

- **A linha `afastamento` mede o que promete.** A API falsa anota a posição depois de **cada**

  - A varredura M=40 deu +188/−188 com o modelo, contra os +189/−189 que o desenvolvedor mediu no

### Sugestões

**1. `server/ferramentas/provar-aceleracao.mjs:21-22` e `:307-310` — "o cursor volta no `finally`"
não vale para Ctrl+C no meio da execução.**

O aviso convida a cancelar com Ctrl+C. Na contagem regressiva isso é inofensivo. Depois dela, o
Node encerra no `SIGINT` sem rodar o `finally`, e então o cursor fica perto do centro, sem voltar à
origem. Nada fica pressionado, porque a bancada não clica, então não há estado preso. Só a frase
promete mais do que acontece.

Bastaria um `process.once('SIGINT', ...)` que restaure e saia, ou a frase dizer "volta ao lugar no
fim (Ctrl+C no meio deixa o cursor onde estiver)". As outras `provar-*.mjs` têm o mesmo
comportamento. Se for mexer, vale uma ATI que trate as três juntas.

**2. `server/src/saida/saida-do-mouse.ts:8` — uma linha de 145 colunas no comentário do cabeçalho.**

A linha não foi requebrada depois da edição desta rodada. O resto do arquivo está em ~100 colunas.
É cosmético.
