# ATI-014 — Pareamento por token e controle de sessão

## Objetivo
Impedir que qualquer aparelho da rede assuma o mouse do PC.

## Escopo
- Primeira conexão: servidor exibe código de 6 dígitos com validade de 60 s; app envia no
  `hello`; servidor emite token persistente.
- Token guardado no `AppData` do usuário (PC) e no armazenamento seguro do aparelho.
- Conexão sem token válido é recusada com `PAREAMENTO_NECESSARIO` ou `TOKEN_INVALIDO`.
- Gerenciar aparelhos pareados pela CLI: listar, renomear e revogar.
- Uma sessão ativa por vez; conexão nova com token válido substitui a anterior, que recebe
  `SESSAO_SUBSTITUIDA` antes de fechar.
- No modo cabo, o pareamento pode ser dispensado por configuração (o cabo já é prova física
  de posse), com o padrão exigindo pareamento.

## Critérios de aceite
- [ ] Aparelho não pareado é recusado e o servidor não injeta nenhum evento.
- [ ] Código expira em 60 s e não é reutilizável.
- [ ] Revogar um aparelho derruba a sessão dele na hora.
- [ ] Token nunca aparece em log nem em arquivo versionado.
- [ ] Reconexão de aparelho já pareado é automática, sem pedir código de novo.
