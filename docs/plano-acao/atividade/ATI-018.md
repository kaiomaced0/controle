# ATI-018 — Mapeador de ações no servidor

## Objetivo
Fechar o outro lado dos perfis: cada controle recebido vira a ação declarada, seja tecla,
scroll, comando interno ou macro.

## Escopo
- `server/src/perfis/mapeador.ts`: recebe pacote de entrada e o perfil ativo, resolve a ação
  e chama o backend de saída.
- Tabela de teclas por nome legível (`w`, `espaco`, `shift-esquerdo`, `f5`) traduzida para
  scancode, documentada.
- Comandos internos: centralizar, calibrar, trocar de perfil, pausar, retomar, segurar giro.
- Macros: sequência de ações com atraso opcional entre elas, com limite de duração para não
  travar o processo, e cancelamento ao soltar o botão.
- Modificadores: uma ação pode combinar tecla + botão (ex.: ctrl + clique).
- Regra de segurança: ao trocar de perfil, soltar tudo que o perfil anterior deixou pressionado.

## Critérios de aceite
- [ ] Cada tipo de ação do schema tem caminho implementado e teste.
- [ ] Trocar de perfil no meio de um botão pressionado não deixa nada preso.
- [ ] Macro em execução é interrompida ao soltar o botão que a disparou.
- [ ] Ação desconhecida é ignorada com aviso, sem derrubar a sessão.
- [ ] Tabela de nomes de tecla documentada em `docs/PERFIS.md`.
