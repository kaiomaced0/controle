# ATI-011 — Ajuste de sensibilidade e zona morta pelo celular

## Objetivo
Entregar o RF-3: o usuário regula a sensibilidade no próprio aparelho e sente o efeito na hora.

## Escopo
- Tela de ajustes no app com controles deslizantes para: sensibilidade X, sensibilidade Y
  (com opção de travar as duas juntas), zona morta, suavização e inversão de cada eixo.
- Mensagem `config` enviada ao servidor conforme PROTOCOLO.md, seção 3.4, com envio
  limitado (no máximo uma a cada 100 ms enquanto o dedo arrasta o controle).
- O servidor satura valores fora da faixa e responde `config-ok` com os valores efetivos;
  o app exibe o que voltou, não o que mandou.
- Persistência: os valores são gravados no perfil ativo, no lado do PC.
- Área de teste na própria tela: um alvo para conferir o ajuste sem sair do app.
- Botão de restaurar padrões.

## Critérios de aceite
- [ ] Mover o controle deslizante muda o comportamento do cursor imediatamente, sem reconectar.
- [ ] Valor absurdo (sensibilidade 5000) é saturado pelo servidor e refletido na interface.
- [ ] Ajustes sobrevivem a reiniciar o app e o servidor.
- [ ] Arrastar o controle não gera enxurrada de mensagens (verificar o limitador).
- [ ] Unidade exibida ao usuário é compreensível (pixels por grau de rotação).

## Notas
Faixas iniciais sugeridas, a validar em bancada: sensibilidade 5 a 120 px/grau (padrão 35),
zona morta 0 a 3 °/s (padrão 0,35), suavização 0 a 0,6 (padrão 0,15).
