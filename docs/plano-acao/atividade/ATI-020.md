# ATI-020 — Gamepad Xbox virtual via ViGEmBus

## Objetivo
Fazer o Windows enxergar um controle Xbox de verdade, alimentado pelo celular — o caminho
que funciona onde a injeção de mouse não funciona.

## Escopo
- Verificação do driver ViGEmBus na inicialização, com mensagem clara e link se faltar.
- Criação e destruição do gamepad virtual junto do ciclo de vida da sessão.
- Implementação de `BackendGamepad`: botões, direcional, dois sticks analógicos, dois
  gatilhos analógicos.
- Estado enviado apenas quando muda (o relatório do gamepad não precisa de 100 Hz constantes).
- Encerramento limpo: remover o dispositivo virtual ao sair, inclusive em caso de erro.
- Documentar a instalação do driver no README do servidor.

## Critérios de aceite
- [ ] O painel de controles de jogo do Windows mostra o controle e reage a todos os botões e eixos.
- [ ] Um jogo com suporte a controle responde normalmente.
- [ ] Fechar o servidor remove o dispositivo virtual (nenhum controle fantasma).
- [ ] Ausência do driver produz mensagem útil, não pilha de erro.
- [ ] Nenhuma alocação por atualização de estado no caminho quente.
