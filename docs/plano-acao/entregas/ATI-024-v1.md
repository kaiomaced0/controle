# Entrega ATI-024 — rodada 1

## O que foi feito

O app de depuração foi **compilado, instalado e aberto no Galaxy S20+ do Kaio** (SM-G985F,
Android 13, serial RQ8N209ND8Z), carregou o JavaScript do Metro pelo cabo, **conectou no servidor**
(`sessão aberta ... transporte=usb`, RTT p50 de 6 ms) e mostrou a aba Medição com o giroscópio
LSM6DSO lendo a 100,6 Hz — print da tela lido abaixo. O Kotlin da ATI-003 (módulo do giroscópio e
`TCP_NODELAY`) **rodou pela primeira vez sem precisar de conserto**: logcat sem `AndroidRuntime:E` e
buffer de crash vazio. Para o Kaio ficou um caminho de um comando só, `npm run android:cabo`
(`app/scripts/rodar-android.js`): monta o JDK 18, compila só a ABI do aparelho, instala, faz os dois
`adb reverse`, sobe o Metro no mesmo terminal e abre o app. O `npx react-native run-android` também
foi testado e funciona com `JAVA_HOME` no JDK 18 e `--extra-params`.

## Decisões tomadas

1. **Node, e não `.ps1`.** A diretriz sugeria `app/scripts/rodar-android.ps1`, e ele foi escrito.
   Na primeira execução, no Windows PowerShell 5.1, o **Kaspersky bloqueou o arquivo via AMSI** como
   "Este script contém conteúdo mal-intencionado e foi bloqueado pelo software antivírus"
   (`ScriptContainedMaliciousContent`), antes de executar uma linha. Não tentei descobrir o que
   disparou a heurística nem reescrever até passar — isso seria contornar o antivírus. Apaguei o
   `.ps1` e fiz a orquestração em Node, que é o padrão de script de bancada do projeto
   (`server/scripts/adb-reverse.mjs`). Para o Kaio o comando continua sendo um só, no PowerShell:
   `npm run android:cabo`.
2. **CommonJS `.js`, e não `.mjs`.** O `npm run lint` do app (`eslint .`, ESLint 8) **não olha
   `.mjs`**, e passado à força o parser da config do RN nem lê a sintaxe. Em `.js` o arquivo entra no
   lint e no Jest do próprio app, e o tsc enxerga os tipos pelo `allowJs`.
3. **Compilar só a ABI do aparelho por padrão** (`-PreactNativeArchitectures=<ro.product.cpu.abi>`),
   como o `--active-arch-only` do run-android: APK de **36,9 MB em vez de 117 MB**, menos tempo de
   compilação e de cópia pelo cabo. `--todas-as-arquiteturas` volta às quatro. A lista de ABIs válidas
   é **lida do `android/gradle.properties`**, não copiada para o script — uma fonte só.
4. **Metro no mesmo terminal, não em janela nova.** O script sobe o CLI do RN direto
   (`node node_modules/react-native/cli.js start`, não `npm start`) para guardar o processo do
   próprio Metro, espera `packager-status:running` em `/status` (o mesmo teste que o app faz) e só
   então abre o app. Ctrl+C derruba os dois; qualquer erro depois do Metro de pé também o encerra —
   ele nunca fica órfão segurando a 8081. Se já houver um Metro de pé, é reaproveitado.
5. **O servidor fica de fora.** O script encaminha a 8765, avisa se nada escuta nela e diz o comando
   (`cd server; npm run dev`), mas não sobe o servidor: ele tem ciclo de vida próprio e, com o
   `movimento: sistema`, mexe no cursor — não é coisa para subir de carona.
6. **`--porta-do-servidor`** existe para o lado do PC; o lado do celular é sempre 8765, porque é o
   `URL_PADRAO` do app. Foi o que permitiu testar contra um servidor na 8770 sem tocar na 8765.
7. **`.\gradlew.bat`, com `.\`.** Com `NoDefaultCurrentDirectoryInExePath` no ambiente (é o caso do
   terminal do agente), o `cmd` não procura executável na pasta atual e o `gradlew.bat` "não é
   reconhecido". O `run-android` tem esse problema; o script não.
8. **Conferências baratas depois do `am start`**: tela bloqueada (`isKeyguardShowing=true`) vira
   aviso, e o processo do app é conferido 5 s depois (`pidof`) — um app que morre ao abrir sumiria
   sem aviso nenhum no PC.

## Achados fora do escopo

1. **ATI-003 destravada.** A medição real de taxa e jitter agora é possível no S20. O print mostra
   números promissores (100,6 Hz, desvio 0,00 ms), mas é um instante de tela, não a medição com
   captura que a ATI-003 pede — fica para ela.
2. **O relay do Telegram está bloqueado pelo filtro web da rede corporativa.** Tentei avisar o Kaio
   para desbloquear o celular (caminho do `CLAUDE.md` global) e o `POST
   https://telegrambotnotificacao.nortedata.com/api/send` voltou a página "Pagina bloqueada!! ...
   Category: malware". Não tentei contornar. Nesta rede, o aviso por Telegram não funciona — vale
   o Kaio saber, porque outras sessões contam com ele. Não é ATI deste projeto.
3. **O Kaspersky marca `.ps1` de bancada como malicioso (AMSI).** Pode ter gerado evento no console
   da organização. Se o projeto precisar de PowerShell no futuro, conversar antes com quem administra
   o Kaspersky; até lá, script de bancada em Node.
4. **Teste quebrado no servidor, de outro agente:** `server/src/principal.teste.ts:840` (ver
   Verificações).
5. **SDK com `platforms;android-35` duplicado** (`android-35` e `android-35-2`): o CMake avisa
   `[CXX5304] ... inconsistent location`. Inofensivo hoje; uma limpeza no SDK Manager resolve.
6. **Avisos de depreciação do build**: `react-native-safe-area-context` usa a API legada de variantes
   do AGP ("will be removed in version 10.0"), e o Gradle avisa "incompatible with Gradle 10". Nada a
   fazer agora; acompanhar ao subir o RN.
7. **O id do aparelho muda a cada execução** (`9c0f4c4d90de` em `s-1`, `412996afc37a` em `s-2`) —
   comportamento já documentado em `conexaoDoApp.ts` até o pareamento (ATI-014). Só registro.

## Riscos e limitações

- **O script é ferramenta desta máquina.** O JDK padrão é `C:\Program Files\Java\jdk-18.0.2`; em
  outra máquina, `--java-home`/`CONTROLE_JAVA_HOME` ou o caminho oficial (`npm run android`).
- **Opções pelo npm no PowerShell não funcionam** (`npm run android:cabo -- --opção` perde o `--`).
  Documentado: opção vai com `node scripts/rodar-android.js --opção`.
- **Tela bloqueada**: o app abre por trás do bloqueio; o script avisa, mas não desbloqueia — e não
  deve.
- **Ctrl+C real não foi exercitado** (o terminal do agente não manda Ctrl+C). O caminho de
  encerramento foi exercitado matando o Metro: o script saiu junto, como previsto. O tratamento de
  `SIGINT` está no código (linha 384), sem prova em terminal interativo.
- **Sem Metro o app de depuração abre na tela vermelha** "Cannot connect to Metro" — é o
  comportamento padrão de build de depuração. Um APK com o JS embutido seria outra ATI, se for
  desejado.
